# UnitEase: Web-Based Property Management System

UnitEase is a web-based system designed to simplify and improve the management of apartments, tenants, and transactions. It provides an organized way for administrators and tenants to interact with property information through an efficient digital platform.



🚀 Features

Admin Side

Manage apartment units

Track tenant records

Real-time tracking of units

Secure access with admin credentials



Tenant Side

View unit details

Send Requests

Access announcements or updates



🛠️ System Requirements

Operating System: Windows 10 / 11 (64-bit)

Server Environment: XAMPP (Apache, MySQL, PHP, phpMyAdmin)

Languages Used: HTML, CSS, JavaScript, PHP

Database: MySQL



📌 Purpose

UnitEase aims to make apartment management faster, clearer, and more organized by offering a centralized system for handling tenants, and unit information.



👥 Stakeholders

Administrators – manage the whole system

Tenants – access their records and updates



📦 How to Run the Project

Install and open XAMPP

Start Apache and MySQL

Copy the project folder into htdocs

Import the included SQL file into phpMyAdmin

Open in browser:

http://localhost/UnitEase/
